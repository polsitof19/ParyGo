# ParyGo — carpeta de marketing con Claude Code

Igual que la carpeta de CODE, pero para vender ParyGo a organizadores.

## Uso
```
cd marketing
claude
```
Claude lee `CLAUDE.md` (contexto, reglas y qué especialista usar) y tiene acá sus agentes y skills.

## Qué hay
- `CLAUDE.md`: el cerebro de marketing de ParyGo.
- `campanas/2026-10-primeros-clientes/plan.md`: plan de 30 días, 10 posts, 3 anuncios, mensajes de contacto, correos de alta abandonada, prospección.
- `auditorias/2026-09-30-landing.md`: auditoría SEO y de conversión de parygo.com y /empezar.
- `pendientes-producto.md`: lo que hay que arreglar en el producto (empieza por lo URGENTE de la landing).
- `datos/`: embudo de prospectos y ventas de packs (llénalos con datos reales).
- `marca/identidad.md`: colores, tipografías y tono.
- `herramientas/`: exportar HTML a PNG (flyers y carruseles), ComfyUI local, quitar fondo verde.

## Ejemplos
- "Usa el TikTok Strategist para guionar el post 3 del plan."
- "Con prospecting y cold-email, arma la hoja de 20 organizadores para esta semana."
- "Revisa este anuncio con marketing-psychology."
